# Bíblia AGB (Audio Games Brasil)

Repositório público de distribuição da Bíblia AGB (Audio Games Brasil).

Versões atuais: **4.5.1 para Windows** e **4.5.1 para Android**.

## Downloads oficiais

- Windows: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/v4.5.1/BibliaAcessivel-Windows.zip
- Android: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/android-v4.5.1/BibliaAcessivel-Android.apk

A versão 4.5.1 traz uma seleção mais clara de temas cotidianos no Teólogo de IA. Antes de escolher o tema, a pessoa decide se o estudo será baseado no texto bíblico atual ou focado na Bíblia toda.

## Site e devocionais

https://audiogames.com.br/diego/biblia/

Os pacotes prontos são publicados nas Releases e utilizados pelos atualizadores de cada plataforma. O código-fonte não é distribuído neste repositório.
