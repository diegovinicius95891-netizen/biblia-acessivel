# Bíblia AGB (Audio Games Brasil)

Repositório público de distribuição da Bíblia AGB (Audio Games Brasil).

Versões atuais: **4.5.4 para Windows** e **4.6.0 para Android**.

## Downloads oficiais

- Windows: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/v4.5.4/BibliaAcessivel-Windows.zip
- Android: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/android-v4.6.0/BibliaAcessivel-Android.apk

A versão 4.5.2 organiza os temas de estudo com IA em ordem alfabética e deixa o fluxo do Android mais claro e acessível.

A versão 4.5.4 para Windows deixa a interface mais limpa, sem opções repetidas. A 4.5.3 fez o Escape voltar pelo mesmo caminho, organiza Mais opções por assunto e salva as configurações na hora.

A versão 4.6.0 para Android traz o Teólogo de IA estável, aviso rápido de devocionais, lembrete diário, planos de leitura, Diário de oração, leitura em voz alta e backup compatível com o Windows.

A versão 4.5.3 para Android dispensa a permissão do microfone, acompanha o tema escuro e economiza bateria na busca por devocionais.
