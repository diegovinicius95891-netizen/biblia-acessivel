# Bíblia AGB (Audio Games Brasil)

Repositório público de distribuição da Bíblia AGB (Audio Games Brasil).

Versões atuais: **4.5.0 para Windows** e **4.5.0 para Android**.

## Downloads oficiais

- Windows: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/v4.5.0/BibliaAcessivel-Windows.zip
- Android: https://github.com/diegovinicius95891-netizen/biblia-acessivel/releases/download/android-v4.5.0/BibliaAcessivel-Android.apk

A versão 4.5.0 acrescenta 2.000 temas pesquisáveis no Teólogo de IA, pesquisa de livros e a opção de reunir os 66 livros.
