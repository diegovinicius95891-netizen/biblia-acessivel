## Novidades

- Atualização automática acessível por GitHub Releases, com verificação diária em segundo plano.
- Download cancelável, validação de tamanho e SHA-256, backup pré-atualização e retorno seguro à versão anterior se a troca de arquivos falhar.
- Dados pessoais migrados para a pasta do perfil do Windows, fora da pasta atualizada.
- Busca bíblica inteligente, 17 planos de leitura, Diário de oração, Meu momento com Deus, favoritos, histórico, temas e memorização.
- Quiz ampliado para 36 perguntas, cobrindo três dificuldades e seis categorias.
- Modo culto aprimorado: Enter mostra e anuncia a passagem imediatamente, sem exigir a ação “Ler versículo”.
- Melhorias de acessibilidade, navegação por teclado, notas, voz SAPI, resumos do Gemini e telas de Ajuda e Leis.

O pacote Windows contém somente o executável, o banco bíblico distribuível e a documentação. Nenhuma anotação, oração, configuração ou chave de API acompanha o download.
