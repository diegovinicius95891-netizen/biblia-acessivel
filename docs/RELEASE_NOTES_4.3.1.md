# Bíblia Acessível 4.3.1 para Windows

- Mais opções ganhou a ação Sair do aplicativo, com confirmação.
- A tela Versículos agora oferece Capítulo anterior, Próximo capítulo e Voltar ao menu principal.
- Esquerda e direita continuam trocando capítulos.
- O leitor de tela anuncia se a pessoa avançou ou voltou e informa o novo livro e capítulo.
- O foco é restaurado imediatamente e novamente após a tela terminar de abrir, evitando transições sem acesso pelo teclado ou leitor de tela.

Esta atualização é exclusiva do Windows. O Android permanece na versão 4.3.0.
