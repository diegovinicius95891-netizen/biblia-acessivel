# Bíblia Acessível 4.3.0 para Windows

- Nova abertura com quatro destinos em telas separadas: Livros, Capítulos, Versículos e Mais opções.
- Atalhos Alt+1, Alt+2, Alt+3 e Alt+4 abrem diretamente essas telas.
- As setas esquerda e direita continuam trocando o testamento dentro de Livros.
- Enter no livro abre Capítulos; Enter no capítulo abre Versículos.
- O Modo culto aceita referências com ou sem pontuação e oferece uma escolha quando o livro é ambíguo.
- Dados pessoais e configurações das versões anteriores são preservados.
