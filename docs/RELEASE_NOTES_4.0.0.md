# Bíblia Acessível 4.0.0 para Windows

## Devocionais publicados no site

- Nova opção **Devocionais novos do site** em Mais opções.
- Consulta a fonte pública `https://audiogames.com.br/diego/devocionais/posts.json`.
- Mostra o histórico completo, com data, título e texto em parágrafos navegáveis.
- Mantém uma cópia local válida para leitura quando a internet ou o site estiverem indisponíveis.
- Procura novidades na abertura e, enquanto o aplicativo estiver aberto, no máximo uma vez por dia.
- Avisa apenas quando o identificador de uma publicação realmente nova é encontrado.
- A notificação pode ser desligada em Configurações.

## Revisão geral

- Windows e Android passam a usar a versão principal 4.0.0.
- Validação estrita do endereço HTTPS, tamanho e formato da fonte pública.
- Gravação atômica do cache: uma falha não substitui a última cópia válida.
- A consulta acontece fora da interface e nunca bloqueia a leitura bíblica.
- Posição, notas, favoritos, quiz, planos, chave de IA e demais dados pessoais são preservados na atualização.
