# Bíblia Acessível 4.2.0 para Windows

- Substitui a antiga lista de marcação por uma caixa de combinação acessível para escolher a tradução padrão.
- Adiciona escolha explícita entre Antigo e Novo Testamento, com anúncio da seção selecionada, quantidade de livros e próximo passo.
- Adiciona Comparar traduções com origem e destino independentes, seções separadas e comando para inverter as edições.
- Mantém somente a primeira resposta de cada pergunta nos totais do quiz.
- Adiciona Recomeçar quiz do zero, com confirmação, como única forma de liberar novamente todas as perguntas.
- Endurece o executável removendo docstrings, asserções e módulos de desenvolvimento não utilizados.
- Mantém verificação de nome, origem, tamanho e SHA-256 dos pacotes de atualização.
- Preserva posição, notas, favoritos, quiz, planos, configurações e chave da inteligência artificial.

Nenhuma proteção torna um programa instalado impossível de analisar, mas as novas camadas reduzem informações disponíveis e dificultam alterações casuais.
