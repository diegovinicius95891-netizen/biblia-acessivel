# Bíblia AGB (Audio Games Brasil) 4.4.0 para Windows

- O menu inicial agora oferece **Continuar leitura** com livro, capítulo e versículo salvos.
- Escape no menu inicial abre a confirmação para sair.
- Configurações permite escolher se Alt+F4 pede confirmação ou fecha diretamente.

- A nova identidade visível é **Bíblia AGB (Audio Games Brasil)**, sem perder dados e preferências das versões anteriores.
